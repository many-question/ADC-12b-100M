# 噪声预算重新分配（架构 v0.3 提案）

> 状态：**提案，待项目负责人批准**。本文回应 issue #12（比较器实测噪声—负载—能量折衷）。
> 规格与模型参数尚未修改；批准后按 §6 实施为架构 v0.3。
> 数字来自系统级模型 `tools/adcflow/model.py`，可用 `python analysis/noise_budget.py --sweep` 重新生成。

## 1. 结论

| 项目 | v0.2 | v0.3 提案 |
|---|---|---|
| 比较器噪声（差分，比较器输入端） | ≤ 80 µV，全部工艺角 | **TT ≤ 200 µV；全部工艺角 ≤ 240 µV** |
| 比较器在非量化噪声功率中的占比（最坏角 / TT） | 20 % / – | **78 % / 76 %**（> 50 %） |
| 单位电容 `cu` | 0.5 fF | **1.0 fF**（权重、冗余不变） |
| C_S / C_DAC（每侧） | 1.0285 / 1.1345 pF | **2.057 / 2.269 pF** |
| 采样 kT/C（125 °C，输入等效） | 113.9 µV | **80.5 µV** |
| LSB、满量程、上极板增益 | 437.5 µV、0.993 V、0.824 | 不变 |
| 最坏角模型 ENOB（全部项按限值叠加） | 11.07（比较器 80 µV） | **10.68 平均 / 10.62 最差芯片，裕量 0.18 / 0.12 bit** |
| TT 模型 ENOB（比较器取 TT 限值） | 11.37 | 10.90（不含失配与失真余量）→ TOP-02 由 11.0 改为 10.8 |

* 用户的决定（比较器 ≥ 180 µV、占非量化噪声 > 50 %、不用低噪声/多模式比较器、不加判决次数）在
  v0.2 尺寸下不可行：比较器全角 240 µV 时最坏角只有 10.58 bit（裕量 0.02 bit）。
* 把 C_S 加倍、并把参考噪声 REF-08 收紧到 80 µV，换回约 0.10 bit；比较器仍占 78 %。
* C_S 再加大收益很小（k = 3 只多 0.03 bit，但参考电流、面积、驱动、50 Ω 负载继续 ×1.5），
  所以取 k = 2。它同时把 LSB 半电容从 0.25 fF 提高到 0.5 fF，消除了 §9 的一项风险，失配 σ 降为 1/√2。

## 2. 方法与最坏角定义

* 每一项单独送入模型（49.9 MHz、−1 dBFS、8192 点相干正弦），由它留下的 SNDR 扣除量化噪声换算成
  输入等效 rms；“合计”把所有项一起打开，对 8 组失配随机数（8 颗“芯片”）给出平均与最差 ENOB。
* **模型中的最坏角** = 同时取：125 °C（kT/C、follower 的 g_s 与噪声最差）；比较器、逻辑、DAC 时序为 TT 的
  1.6 倍（慢角上限，`docs/architecture.md` §5）；比较器噪声取**全角**限值；参考噪声取 REF-08 限值；
  失真与失配余量。真实电路中这些最坏情况不会出现在同一个工艺角（比较器噪声最大的通常是 ff/125 °C，
  时序最慢的是 ss/0.81 V），因此叠加是保守的。
* 采样 kT/C 用 `2kT·C_tot/C_S²`。底板采样时上极板开关断开冻结的是上极板节点的电荷，其方差在热平衡下
  恰为 kT·C_tot（与各电阻大小无关），所以**输入开关、上极板开关和 50 Ω 源的热噪声都已包含在内**；
  50 Ω 源实际在室温，按芯片温度计是保守的。
* 参考：行为级 follower（与 CDAC 电荷同比例放大，见 §5.3），把其白噪声提高到 REF-08 限值（27 °C）。
* 失真余量：采样网络静态 HD3 −82 dBc（= BST-05 的 SFDR 限值）。
* 失配余量：随机单位电容失配，按标称权重解码（TOP-01 的验收方式）。v0.2 要求 σ(cu) ≤ 1 %（0.5 fF）；
  面积加倍后同一 Pelgrom 系数给出 0.71 %（1.0 fF）。

**裕量取 ≥ 0.15 bit（平均芯片）且 ≥ 0.1 bit（8 颗中最差）**，留给模型之外的项：电源/衬底噪声、
比较器回踢与记忆效应、布局寄生、开关电荷注入失配、比较器噪声随工艺角的分布比假设更宽等。
没有取 0.2 bit，是因为上面已经把每个模块都放在限值、并且把不同角的最坏情况叠在一起；
若负责人坚持 0.2 bit，把比较器全角限值降到 230 µV 即可（约 +0.03 bit，见 §3.3 扫描），代价是
TT/全角之比只剩 1.15。

## 4. 比较器指标（`adc_comp` 0.1.0 → 0.2.0）

| 编号 | 指标 | v0.2 | v0.3 | 依据 |
|---|---|---|---|---|
| CMP-01 | 输入等效噪声（差分 rms） | ≤ 80 µV，全部角 | **≤ 200 µV，TT** | `mc12` TT 实测 193.5 µV（4 种子合并） |
| CMP-13（新） | 输入等效噪声，全部角 | – | **≤ 240 µV，全部角** | 预算的最坏角值；TT/全角之比 1.2 |
| CMP-04 / 05 | 1 mV 时延 | TT 80 ps / 全角 120 ps | 不变 | `mc12` 59 ps / quick 角最大 94 ps |
| CMP-06 | 30 mV 时延，TT | 50 ps | 不变 | `mc12` 47.7 ps；环路时序预算不变 |
| CMP-07 / 08 | τ_reg / 复位 | 15 / 35 ps | 不变 | `mc12` 9.0 / 27.6 ps（quick 角最大） |
| CMP-10 | 每次比较能量，TT | 150 fJ | **200 fJ**（软目标） | 给输入对与积分电容留尺寸余地；0.28 mW，远小于参考驱动 |
| CMP-11 | 每周期差分回踢 | ≤ 40 µV，1.25 pF 上 | **≤ 40 µV，2.5 pF 上** | 测试电容随 C_tot（2.50 pF）更新；限值仍约 0.1 LSB |
| CMP-12 | 每端输入电容，TT | 15 fF | **20 fF** | C_DAC 加倍后占比 0.9 %（v0.2 为 1.3 %），仍在 10 % 上极板寄生预算内 |
| CMP-02 / 03 / 09 | 失调 / 失调 σ / 判决错误 | 2 mV / 5 mV / 0 | 不变 | |

* 这一组限值可以同时满足：`mc12` 已在 TT 满足除噪声外全部项，并在 200 µV 以内；放宽的 Cin 与能量
  只是给全角噪声（240 µV）留出尺寸余地（`mc14`：Cin 28.6 fF 时 143 µV，因此 20 fF 时约可降 10~15 %）。
* 全角噪声尚无实测。StrongARM 类比较器的噪声在 125 °C 约升高 15~35 %（kT 上升、gm/I 下降、积分时间变短），
  ff 角积分时间更短也偏高；1.2 倍是有依据的目标，需比较器负责人用 `--corners all` 的噪声测试确认。
* **测试台**：σ ≈ 200 µV 时现有 `tb_comp_noise` 的 ±300 µV 扫描只覆盖约 ±1.5σ，`mc12` 四个种子的拟合
  从 177 到 226 µV 分散。建议改为 ±800 µV、17 个电平（步长 100 µV）、每电平 128 次判决
  （仿真时间约 ×2.6），使 σ 拟合的统计误差降到约 ±5 %。

## 5. C_S / C_DAC 加倍的连带影响

### 5.1 采样网络（`adc_bootstrap`、`adc_cdac` 输入开关）

* 输入开关按 C_S 同比放大：参考开关 48 µm → 96 µm（25 Ω → 12.5 Ω），R·C 不变，因此开关导通电阻非线性
  引起的失真不变。上极板复位开关同样加倍（行为级 20 Ω → 10 Ω）。
* 跟踪时间常数 (50 + 12.5 + 10) Ω × 2.057 pF ≈ 149 ps（v0.2 约 98 ps），−3 dB 带宽约 1.07 GHz；
  50 MHz 处只是线性的增益/相位误差（−0.01 dB）。跟踪窗口约 4.1 ns = 27τ；跟踪开始时底板从
  VREFP/VREFN 跳到 VIN（每侧最多约 0.93 pC），约 1.4 ns 内建立到 0.1 LSB。
* 底板结电容（输入开关与三态驱动器的扩散区）的非线性电流流过 50 Ω 源，这一项随 C_S 加倍 +6 dB。
  估算（突变结、每侧 NMOS 型扩散电容）：100 fF/侧时 HD3 ≈ −97 dBc，200 fF/侧时 ≈ −91 dBc，
  仍低于 −82 dBc 的失真余量。DAC-09（≥ 85 dBc）、BST-05（≥ 82 dBc）不变。
* 自举电路的负载（开关栅电容）加倍：自举电容同比加倍，BST-07 电流 25 → 50 µA；
  BST-03 关断 ≤ 60 ps、BST-04 开启 ≤ 300 ps 不变（更难，需更大的放电/充电器件）。

### 5.2 CDAC 开关与建立（`adc_cdac`）

* 驱动器按电容同比放大，时间常数不变：DAC-05/06/07/08（建立时间与 τ）保持原值。
* DAC-13 控制输入电容保持 ≤ 6 fF，SAR 逻辑的 UP/DN 负载（12 fF）因此不变；大权重位的驱动器在 CDAC 内部
  多约半级 FO4 缓冲（TT 约 5 ps），计入 DAC-05/06 的建立时间。DAC-06（MSB 40 ps 内到 5 %）对应误差
  49 LSB，判决 1 的冗余为 310 LSB，余量仍大。
* DAC-01：C_S 0.99~1.06 pF → **1.98~2.12 pF**。DAC-12：每次转换 VREFP 电荷（每侧）0.6 → **1.2 pC**
  （v0.2 行为级实测 0.39 pC → 约 0.78 pC）。上极板负载（比较器输入）15 → 20 fF。
* 失配：v0.2 要求 σ(cu) ≤ 1 %（0.5 fF）；v0.3 预算按同一 Pelgrom 系数取 σ(cu) ≤ 0.71 %（1.0 fF）。
* **发现的问题（与本次重新分配无关，但属于失配余量）**：DAC-03 允许每个权重 0.5 % 的系统误差。
  按标称权重解码时，MSB（980）单独 0.5 % 的误差就产生约 930 µV 的输入等效误差（ENOB 约 9），0.1 % 时
  185 µV；13 个权重各 ±0.1 LSB 时 147 µV。0.5 % 远松于预算。建议把 DAC-03 改为
  “由实测权重按标称权重解码的 ENOB 损失 ≤ 0.05 bit”（度量函数用实测权重调用系统模型），
  或改为绝对误差（如每个权重 ≤ 0.03 LSB）。是否纳入 v0.3 由负责人决定。

### 5.3 参考（`adc_ref`，`tb_ref_replay`）

* 每次转换的电荷全部 ×2：起始 0.93 pC、13 次切换 1.02 pC（MSB 0.44 pC）、与信号相关部分 ≤ 0.36 pC，
  平均约 0.2 mA。电压容差（REF-12/13/14、冗余）不变，因为 LSB 与 VREF 不变。
* follower 电流与节点电容同乘 k 时，VREFP 的电压波形与 v0.2 完全相同（模型：ENOB 损失 0.006 / 0.016 bit、
  判决 12~14 期间变化 59 / 104 µV，27 / 125 °C，与 v0.2 一致）。**行为级起点改为 4 mA + 3.0 pF**
  （节点 4.2 pF，仍是 pF 级、片内）。较省电的选择（设计者决定）：3 mA + 2 pF 在 125 °C 损失 0.039 bit、
  变化 140 µV；3 mA + 3 pF 为 0.093 bit / 169 µV，接近限值；2.5 mA 不够。
* REF-08 噪声 120 → **80 µV**（TT，10 kHz~100 GHz）。120 µV 单独就要 0.12 bit，在新预算中太贵；
  4.2 pF 节点的热噪声底约 44 µV（γ = 2，27 °C），给闪烁噪声与偏置噪声留了余地。
* 测试台：`tb_ref_replay`、`tb_ref_noise` 中模拟 CDAC 底板的电容 0.6 → 1.2 pF；回放电荷由
  `Arch` 自动加倍。VCM 负载 2 × 1.25 pF → 2 × 2.5 pF。
* AVDD18 功耗（行为级）约 3.8 → 7.6 mW。

### 5.4 比较器输入电容、回踢

* Cin / C_DAC：v0.2 15 fF / 1.13 pF = 1.3 %；v0.3 20 fF / 2.27 pF = 0.9 %。上极板寄生（含比较器）上限
  仍为 10 % C_DAC（227 fF），因此上极板增益 ≥ 0.824 的预算不变，实际会略好。
* 回踢：同样电荷在 2.5 pF 上只产生一半电压；限值保持 40 µV（约 0.1 LSB，输入等效），即允许的回踢电荷 ×2。
  `mc12` 为 0.014 µV。

### 5.5 时钟相位（`adc_clkgen`）

* PHI_S/PHI_SB 驱动的上极板开关加倍：负载 60 → **100 fF**（估计值），CLK-06 下降时间 ≤ 20 ps 不变。
  PHI_B/PHI_BB（自举输入）不变；CONV 负载 250 fF 不变（CDAC 内部缓冲三态使能）。

### 5.6 面积、时序与功耗

* 面积：CDAC 电容阵列、输入开关、驱动器加倍（两侧共 4.5 pF），自举电容加倍，参考去耦 1.5 → 3 pF。
* 异步环路时序：比较器时序与 CDAC 建立规格不变，SAR 逻辑接口不变，因此慢角预算与 v0.2 相同
  （×1.6 时 t_conv 最大 4.12 ns，无未完成转换）。
* 功耗（软目标）：参考 2 → 4 mA；CDAC 从 VREFP 取的平均电流 0.1 → 0.2 mA；比较器 ≤ 0.28 mW；
  自举 2 × 50 µA；CDAC 驱动 DVDD 功耗约 ×2。合计约 4.4 → 8 mW，Walden FoM 约 40 fJ/conv-step（ENOB 10.9）。
